# Edversity Submission Notes

This repository contains the reusable Terraform source code and setup instructions.

For assessment evidence, attach:
1. The project report PDF supplied separately.
2. Screenshots of the AWS VPC and EC2 resources (with sensitive values hidden).
3. Screenshot of `terraform validate` success.
4. Screenshot of `terraform workspace list` showing default, dev, and qa.
5. Screenshot of `terraform state list` for the QA workspace.
6. Screenshot of S3 showing the remote-state objects (do not expose credentials).

The included `.tfvars.example` files and `backend.tf.example` use placeholders. Configure your own values before deployment. Do not upload state files, access keys, secret keys, or private SSH keys.
